# MeowPi-3
## on a clean install of **rpi os 32bit lite** Install with:
```
cd ~
sudo apt install -y git
git clone https://github.com/MonomCZ/MeowPi-3.git
cd MeowPi-3
bash SETUP.sh
```
then run with either
```
bash run_bad_usb.sh
```
or
```
bash run_evil_twin.sh
```
